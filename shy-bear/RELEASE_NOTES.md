# Мишка 5.3.1 — объёмное сердце

Отдельное послание в правом нижнем углу экрана, без мишки: глянцевое сердце размером 1,5 размера анимационной ячейки мишки с надписью «Вам хотят напомнить как сильно вас любят и ценят» шрифтом Mojangles. Плавное появление, лёгкое покачивание и исчезновение, таймер 60 кадров/с.

Отправка из панели, локальный просмотр из меню трея. Показ 12,5 секунды вместе с переходами. Оба ПК должны обновиться для новой команды.
